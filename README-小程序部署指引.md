# PowerUp 单词冒险 · 微信小程序部署指引

艾宾浩斯遗忘曲线背单词小程序。代码已全部写好，按下面步骤操作即可上线。  
全程约半天，每一步都有说明；遇到问题随时回来问我。

## 一、准备（约 20 分钟）

### 1. 注册小程序账号

1. 打开 <https://mp.weixin.qq.com> → 右上角「立即注册」→ 选「小程序」
2. 用邮箱注册（未注册过公众号/小程序的邮箱），主体选「个人」，微信扫码实名
3. 注册后进入后台 → 「开发管理」→「开发设置」→ 复制 **AppID**（形如 `wx1234abcd5678efgh`）

### 2. 安装微信开发者工具

- 下载：<https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html>
- 选 macOS 稳定版，安装后用微信扫码登录

## 二、导入项目（约 10 分钟）

1. 打开微信开发者工具 → 「导入项目」
2. 目录选择本项目根目录：`powerup`（即本文件所在目录）
3. AppID 填第 1 步复制的 AppID（或先选「测试号」体验，正式发布前再换）
4. 打开 `project.config.json`，把 `"appid": "touristappid"` 改为你的 AppID

## 三、数据存储：不需要云开发（0 分钟）

学习进度保存在**本机微信缓存**（`wx.setStorageSync`），不联网、不上传、无需云环境。这一节什么都不用做。

> **为什么不用云开发**（2026-09-29 改）：云开发免费环境有 6 个月有效期，到期停服销毁、数据不可恢复；小程序发布上线后，免费环境还会被改成「上线后第 15 天」到期，续期无效，想长期用只能买个人版 19.9 元/月。孩子固定一台设备使用时，跨设备同步不是必需项，所以改成「纯本地 + 手动备份」。
> 若你已按旧版开通了云环境，不用处理它，代码已不再调用；以后想恢复云同步，代码在 git 历史里有（见「进度备份」一节末尾）。

## 四、配置发音域名（约 3 分钟，真机必须）

单词发音用有道语音接口（英音，与 Power Up 剑桥教材口音一致）。真机播放网络音频需配白名单：

1. mp 后台 →「开发管理」→「开发设置」→「服务器域名」
2. `downloadFile 合法域名` 添加：`https://dict.youdao.com` → 保存
3. 开发者工具重新「预览」生成新二维码再扫码测试

> 说明：曾评估微信官方「同声传译」插件（本地合成免域名），但该插件不对个人主体/部分类目开放（添加时报"类目或主体类型不符合要求"），故采用有道方案。
> 开发期可在「详情 → 本地设置」勾选「不校验合法域名」临时跳过，**正式发布前必须配置**。

## 六、提交审核发布（约 10 分钟 + 审核 1~7 天）

1. 开发者工具右上角「上传」→ 填版本号 `1.0.0`、备注「首个版本」
2. mp 后台 → 「版本管理」→ 开发版本 → 「提交审核」
   - **首选**：「教育 → 教育信息展示」（个人主体后台实际显示名；官方文档/旧资料里叫"教育信息服务"，是同一个类目，个人主体可申请、无资质要求）
   - **兜底**：若后台提示需《民办学校办学许可证》等资质、或审核以类目不符驳回，改选「工具 → 效率」或「工具 → 信息查询」（个人主体明确开放、暂无资质要求，最稳）
   - 判断方法：个人主体账号在后台「设置 → 服务类目」里**只显示开放给个人的类目**，能选且系统不要求上传资质即代表可用，以后台实际列表为准
   - 注意：选了教育类目就不能出现视频课程、直播、付费课程等内容；本小程序是纯卡片+消消乐，无视频无直播无付费，不会冲突
   - 建议只选 1 个类目（最多可填 5 个，类目越多审核越易挑"功能与类目不符"）
   - 另：小程序现已强制 ICP 备案，个人主体备案时服务内容不要选经营性质类
3. 审核通过后点「发布」，全量上线
4. 把小程序分享给家人：mp 后台「版本管理」生成小程序码，或微信里直接转发

## 七、隐私合规（提审必填）

**代码实况**（2026-09-29 重新核查）：
- **不收集任何用户信息**：无 `wx.login`、无 openid、无头像昵称、手机号、位置、相册、通讯录、录音
- 进度只存本机，无后端、不上传、不向第三方共享
- 备份功能刻意避开了隐私接口：导出用 `wx.shareFileMessage`（用户主动分享出去，非收集行为），导入为手动粘贴文本——**没有**用 `wx.getClipboardData`、`wx.chooseMessageFile`（这两个属隐私接口，用了就必须在指引里声明"剪贴板/选中的文件"）

**因此提审时**：
1. 提交审核页 →「用户隐私保护设置」→ 可勾选**"不采集用户隐私"**（代码确实不采集）
2. **不需要**在代码里加 `wx.requirePrivacyAuthorize` / `onNeedPrivacyAuthorization` 弹窗
3. 若后台仍提示需填《用户隐私保护指引》，按实际情况如实填写即可，收集项留空/不勾选

> 变更说明：旧版本用云开发，写入时会自动注入 `_openid`，在合规上属于"处理用户个人信息"，必须填指引并勾选"采集"。改为纯本地后这两项都不再需要，审核也更简单。

## 常见问题

**Q：还需要开云开发吗？**  
不需要（2026-09-29 起已改为纯本地）。进度存在这台设备的微信缓存里，不联网不上传；换设备用「设置 → 进度备份」导出/导入。省掉 19.9 元/月，也不用担心免费环境到期把数据销毁。

**Q：发音没声音？**  
① 检查第四步域名配置；② 手机别静音（iPhone 静音键会屏蔽 InnerAudio 的声音，这是 iOS 限制，可在代码里后续加 obeyMuteSwitch:false，需要的话告诉我）。

**Q：重置后悔了能恢复吗？**  
不能。重置前会要求输入「重置」二字确认，请谨慎。如需"重置前自动备份"，告诉我加。

**Q：想改复习间隔/每日上限？**  
都在 `miniprogram/utils/logic.js` 顶部：`INTERVALS = [1,2,4,7,15,30]`，改数字即可；单日新词上限是每日额度 ×2（`todayNewAllowance` 里的 cap）。

## 云开发环境到期怎么办（重要）

云开发**免费版环境有有效期**（微信云开发免费体验环境 6 个月，CloudBase 免费版单次 6 个月、到期前 1 个月内可续）。到期后环境停服 → 隔离 → 销毁，**数据不可恢复**。

**环境停服后小程序不会崩**：代码是「本地优先 + 云端兜底」，`saveCloud` 失败被 catch 忽略，本地进度照常读写。唯一损失是**跨设备同步**（换手机进度不同步）。

### 三条路怎么选

| 方案 | 成本 | 保留同步 | 适用 |
| --- | --- | --- | --- |
| ① 控制台续期 | 0 | 是 | 仍在开发/未上线；上线后失效（免费环境上线后按「上线第 15 天」到期） |
| ② 转付费环境 | ¥19.9/月（个人版/基础套餐，约 240 元/年） | 是 | 已上线、要长期用、要跨设备同步 |
| ③ 去掉云开发，纯本地存储 | 0 | 否 | 固定一台设备自用；可接受换机丢进度 |

### 无论如何，先备份

到期销毁不可恢复，**先导出一次**：
云开发控制台 → 数据库 → `words_progress` 集合 → 导出（JSON/CSV）→ 存本地。
进度数据只有几 KB，导入回去也很快（控制台 → 导入 → 选集合）。

### 本项目已按方案 ③ 改完（2026-09-29）

代码改动：`app.js` 去掉 `initCloud/loadCloud/saveCloud`；`utils/storage.js` 精简为纯本地；新增 `utils/backup.js`（导出/导入）；设置页新增「💾 进度备份」卡片。逻辑层未动，56 项测试全绿。

**导出**：设置 →「📤 导出备份」→ 弹出分享，发给「文件传输助手」或自己的微信，得到 `卡卡记单词-进度-2026-09-29.txt`（内容是 JSON 文本，微信里可直接打开看）。建议每月、以及换机/清缓存前导一次。

**导入**：新设备打开小程序 → 设置 →「📥 导入备份」→ 在微信里打开那个 `.txt`，长按全选复制 → 粘贴进输入框 →「导入并覆盖」。会先弹窗对比「当前 X 词 / 备份 Y 词」，确认后才覆盖。

**不支持分享文件的机型**：导出会自动降级——直接把进度文本显示在弹窗里，长按全选复制，粘到微信收藏即可。

**想改回云同步**：git 历史里有旧版 `storage.js` / `app.js`（云开发版），`git log` 找回即可；届时买个人版 19.9 元/月，不要再用免费环境。

## 技术说明（备查）

- 纯原生小程序，**无后端、无云开发、无账号体系**；除单词发音（有道音频）外不发起任何网络请求
- 进度存储：本机缓存（`wx.setStorageSync`）；换设备/清缓存靠「设置 → 进度备份」导出导入（`miniprogram/utils/backup.js`）
- 逻辑层 `miniprogram/utils/logic.js` 是纯函数，Node 测试 56 项全绿（`tests/test-ebbinghaus.js`）
- 词库 505 词（L1 286 + L2 219），顺序即学习顺序，来自剑桥 Power Up 1/2 单元 + YLE 考纲
